# FixIt Campus

FixIt Campus is a classroom problem reporting system designed as a simple mobile app interface for reporting and tracking classroom issues. It is built as a static website and is ready to deploy on Vercel.

## Features
- Report a classroom problem
- Select problem type, location, and description
- View report confirmation screen
- Check all submitted reports
- View report details and status
- Browser-based local storage persistence

## Run locally
Open `index.html` directly in your browser, or serve the folder with a simple HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy on Vercel
1. Push this repository to GitHub.
2. Go to https://vercel.com
3. Click "Add New Project"
4. Import this repository
5. Keep the default settings and click "Deploy"

## Files
- `index.html` – complete app UI and JavaScript logic
